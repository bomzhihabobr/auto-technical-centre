# Auto Technical Centre — сайт техосмотра

Одностраничный сайт центра техосмотра с формой записи и административной панелью.

## Локальный запуск

1. Установите зависимости: `npm install`.
2. Запустите backend: `npm start`.
3. Откройте `http://localhost:3003/`.

Форма записи и админ-панель используют Express API и SQLite (`database.db`). Не публикуйте базу данных и файлы сервера в открытом доступе.

## Подготовка к Netlify

`npm run build` собирает только страницы `index.html`, `login.html`, `admin.html`, `privacy.html` и папку `assets` в `dist`. База, резервные копии и служебные файлы не попадают в сборку. После публикации сайт получит бесплатный адрес вида `имя-проекта.netlify.app`.

**Перед включением онлайн-записи необходимо перенести API и данные на серверless backend и постоянную базу данных.** Netlify не запускает постоянный Express-процесс, а локальный SQLite-файл нельзя использовать как хранилище заявок в Netlify Functions. Без этой настройки опубликованные форма и панель не смогут сохранять/читать заявки. Следующий шаг — связать проект с аккаунтом Netlify, затем подключить API и базу и только после этого публиковать рабочую запись.

## Страницы

- `index.html` — главная и запись
- `login.html` и `admin.html` — вход и панель администратора (доступ через URL)
- `privacy.html` — политика обработки данных
- `server.js` — локальный Express backend
