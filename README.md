# ATC — Техосмотр в Астане (лендинг)

Современный одностраничный сайт для центра техосмотра «Auto Technical Centre» (Астана), вдохновлён дизайном и анимациями to-smotr.ru и наполнен вашим контентом.

## Содержимое
- `index.html` — главная страница с секциями: герой, обязателен/не требуется, шаги, преимущества, подготовка, доп.услуги, FAQ, контакты/запись, футер
- `assets/css/style.css` — стили (адаптив, тёмная тема, тени, градиенты, анимации)
- `assets/js/main.js` — скрипты (бургер-меню, плавный скролл, AOS-анимации, маска телефона, отправка заявки в WhatsApp)
- `assets/img/` — папка для изображений

## Как запустить локально
1. Откройте файл `index.html` двойным кликом — страница откроется в браузере.
2. Если у вас включена защита от локальной загрузки CDN, используйте простой HTTP-сервер:
   - Python 3: `python -m http.server 8000`
   - Node.js: `npx http-server -p 8000`
   Затем откройте http://localhost:8000/

## Редактирование контента
- Телефоны, адрес, e-mail находятся в `index.html` в секции «Контакты» и в верхней панели.
- Тексты FAQ, «обязателен/не требуется», «шаги» — в соответствующих секциях внутри `index.html`.
- Цвета/шрифты — в `assets/css/style.css`.

## Форма записи
Форма не отправляет данные на сервер — она открывает WhatsApp с предзаполненным сообщением на номер `+7 700 243 30 10`. Изменить номер можно в `assets/js/main.js` (переменная `wa` в обработчике формы) и в ссылке WhatsApp в шапке/контактах.
