Политика обработки данных

Здесь описано, какие данные нужны для записи на техосмотр, зачем они используются и как связаться с центром по вопросам обработки данных.

Кто обрабатывает данные

Заявки обрабатывает Auto Technical Centre. Для связи по вопросам записи и обработки данных используйте телефон или электронную почту ниже.

Какие данные мы получаем

При отправке заявки сайт получает имя, номер телефона, марку и модель автомобиля, тип транспорта, выбранную услугу, желаемые дату и время, а также комментарий, если вы его добавили.

Для чего нужны данные

Данные используются для регистрации и обработки записи, проверки доступности времени, связи с вами для подтверждения и ведения внутреннего учета заявок. Данные из формы не публикуются на сайте.

Доступ и хранение

Заявки хранятся в базе данных сайта и доступны сотрудникам, которым они нужны для обработки записи. Данные следует хранить только столько, сколько необходимо для этих целей и выполнения применимых требований законодательства.

Ваши запросы

Вы можете обратиться, чтобы уточнить, исправить или удалить данные, а также отозвать согласие, если это допускается применимым законодательством. Укажите номер заявки и удобный способ обратной связи.
